# Brainrot Lab: Merge

Казуальная merge-idle игра для Яндекс Игр в сеттинге итальянского брейнрота.
План разработки, монетизации и удержания — в [PLAN.md](PLAN.md).

## Запуск для проверки

Нужен Node.js 18+ (https://nodejs.org).

```bash
git clone https://github.com/damilp320-spec/yandex-game.git
cd yandex-game
git checkout claude/yandex-games-plan-ke763a   # пока PR не смержен
npm install
npm run dev
```

Открой http://localhost:5173 — игра запустится сразу.

Вне платформы Яндекса SDK не активен, поэтому включаются **dev-моки**:
- rewarded-реклама «показывается» мгновенно и сразу даёт награду;
- interstitial пишется в консоль браузера (`[mock] interstitial`);
- покупки заменены на `confirm()`-диалог — жми ОК, и товар «куплен»;
- сохранения идут в localStorage (очистить прогресс: DevTools → Application → Local Storage → удалить ключ `save`).

Проверка продакшен-сборки: `npm run build && npm run preview` → http://localhost:4173.

## Свои картинки вместо процедурных спрайтов

Промпты для генерации — в [PROMPTS.md](PROMPTS.md). Готовые PNG положи в `public/skins/` (спрайты `<id>_<0-5>.png`, фоны `bg_<локация>.png`) и перечисли в `public/skins/manifest.json`:
`{ "sprites": ["coffee_0", "sixseven_5"], "backgrounds": ["lab"] }` — что не перечислено, рисуется кодом.

## Свои звуки вместо синтезированных джинглов

1. Положи mp3-файлы в `public/sounds/` с именами: `merge`, `order`, `discovery`, `fanfare`, `coin`, `fail`, `tada` (любое подмножество).
2. Создай `public/sounds/manifest.json` со списком того, что положил: `["merge", "order"]`.
3. Готово — файлы автоматически заменят синтез, остальные звуки останутся синтезированными.

## Публикация на Яндекс Играх

1. `npm run build:yandex` → соберётся `brainrot-lab-merge.zip` (index.html уже в корне архива).
2. Загрузить архив в [консоль разработчика](https://games.yandex.ru/console/) → черновик игры.
3. В консоли настроить:
   - **Покупки** с теми же ID, что в `src/shop.ts`: `starter`, `gems_s`, `gems_m`, `gems_l`, `no_ads` (цены задаются в консоли);
   - **Лидерборд** с ID `weekly_merges`;
   - Rewarded/interstitial включаются автоматически через RTB.
4. Создать счётчик на https://metrika.yandex.ru и вписать его номер в `METRICA_ID` (`src/config.ts`), цели создать по именам из `src/analytics.ts`.
5. Пройти модерацию (чек-лист — PLAN.md §5).

## Деплой в 1 клик (демо-версия)

После мержа в `main` игра автоматически деплоится на GitHub Pages (workflow `.github/workflows/deploy.yml`).
Один раз включи Pages: репозиторий → Settings → Pages → Source: **GitHub Actions**. Запустить вручную: вкладка Actions → Deploy to GitHub Pages → Run workflow.

## Что уже реализовано

- Merge-поле 5×6 с крупными существами (6-й ряд открывается за монеты или кристаллы), 12 цепочек × 6 уровней, drag&drop
- Экономика в духе Steal a Brainrot: каждое существо на поле пассивно приносит монеты раз в 5 секунд; тап по существу — мгновенные монеты с комбо ×5; существа покупаются за растущую цену; бусты дохода ×2 (реклама) и ×3 (кристаллы)
- Четыре локации со своими фонами: «Лаборатория», «Неон-Клуб», «Ночной Дозор», «Космо-База» (капибара-космонавт, НЛО, спагетти-джентльмен)
- «Золотой брейнрот» пролетает по экрану раз в ~90 сек — тап даёт 2 минуты дохода разом
- «Битва недели»: две команды персонажей, очки за слияния своей команды, кристаллы в конце недели, кнопка «позвать друзей»
- **Локализация**: RU / EN / TR (`src/i18n.ts`) — язык берётся из выбора игрока, иначе из `ysdk.environment.i18n.lang`, иначе из браузера. Имена существ в RU свои, в EN/TR — латиница в «итальянском» духе (так мем-персонажей знают в мире). Настройки: ⚙️ в правом верхнем углу — звук, язык, сброс прогресса.
- **Симуляция баланса**: `npm run sim` — прогон 14 игровых дней экономики и тысяч боёв по реальным константам игры (`src/config.ts`, `src/arena.ts`). Показывает доход vs цену существ, плато кубков для каждого уровня казармы, длительность боя и калибровку ценности типов атак бисекцией. Менял баланс — перезапусти и сверься.
- **Арена (PvP)**: команда из 5 брейнротов (боец снимается с поля и перестаёт приносить доход), автобатлер с HP-барами, цифрами урона и ×2; у каждой цепочки свой архетип (урон/HP/скорость, типы атак melee/sniper/splash); соперники генерируются под кубки игрока с правдоподобными никами — «оффлайн противника» не существует; кубки, 6 милстоунов наград, сундук за каждую 3-ю победу, реванш с бустом ×1.2 за рекламу, казарма (атака/броня +5% за уровень, бесконечный синк монет), лидерборд по кубкам (Yandex SDK, id `cups`)
- Именование легендарок: игрок даёт своё имя существу 6-го уровня (остаётся в Мемпедии) + кнопка «похвастаться»
- Секретный «67»: выпадает из сундуков с шансом 6,7%, панель «хвастовства» копирует текст для соцсетей
- Процедурные спрайты 128px с тенями, бликами, щёчками и аксессуарами уровней (ноль бинарных ассетов)
- Джинглы на WebAudio: у каждой цепочки свой тембр, арпеджио слияний растёт с уровнем, фанфары за достижения
- Яндекс.Метрика (`src/analytics.ts`): цели session_start, merge_high, order_done, ad_rewarded, ad_interstitial, purchase_*, zone_unlock, daily_claim, event_milestone
- Заказы: награда равна доходу существа за 3 минуты (растёт с уровнем И цепочкой), каждый 12-й заказ — сундук; одна кнопка добычи существ: бесплатно по кулдауну (25 с) либо сразу за монеты
- Ежедневный бонус (7-дневная серия, спасение серии за рекламу), ежедневные квесты, Мемпедия
- Офлайн-доход с ×2 за rewarded, недельный лидерборд
- Сезонные события по датам из конфига (`src/events.ts`) с милстоунами наград
- Магазин: стартер-пак, пакеты кристаллов, «без рекламы»; синки: сундук (3% секрет), энергия, 7-й ряд
- Обёртка Yandex SDK: реклама с капами, облачные сейвы, платежи, Gameplay API — всё с dev-моками
