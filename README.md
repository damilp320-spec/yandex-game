# Brainrot Lab: Merge

Казуальная merge-idle игра для Яндекс Игр в сеттинге итальянского брейнрота.
План разработки, монетизации и удержания — в [PLAN.md](PLAN.md).

## Запуск для проверки

Нужен Node.js 18+ (https://nodejs.org).

```bash
git clone https://github.com/damilp320-spec/yandex-game.git
cd yandex-game
git checkout claude/yandex-games-plan-ke763a   # пока PR не смержен
npm install
npm run dev
```

Открой http://localhost:5173 — игра запустится сразу.

Вне платформы Яндекса SDK не активен, поэтому включаются **dev-моки**:
- rewarded-реклама «показывается» мгновенно и сразу даёт награду;
- interstitial пишется в консоль браузера (`[mock] interstitial`);
- покупки заменены на `confirm()`-диалог — жми ОК, и товар «куплен»;
- сохранения идут в localStorage (очистить прогресс: DevTools → Application → Local Storage → удалить ключ `save`).

Проверка продакшен-сборки: `npm run build && npm run preview` → http://localhost:4173.

## Публикация на Яндекс Играх

1. `npm run build` → готовая игра в папке `dist/`.
2. Запаковать **содержимое** `dist/` в zip (index.html в корне архива).
3. Загрузить в [консоль разработчика](https://games.yandex.ru/console/) → черновик игры.
4. В консоли настроить:
   - **Покупки** с теми же ID, что в `src/shop.ts`: `starter`, `gems_s`, `gems_m`, `gems_l`, `no_ads` (цены задаются в консоли);
   - **Лидерборд** с ID `weekly_merges`;
   - Rewarded/interstitial включаются автоматически через RTB.
5. Создать счётчик на https://metrika.yandex.ru и вписать его номер в `METRICA_ID` (`src/config.ts`), цели создать по именам из `src/analytics.ts`.
6. Пройти модерацию (чек-лист — PLAN.md §5).

## Что уже реализовано

- Merge-поле 6×7 (7-й ряд открывается за монеты или кристаллы), 6 цепочек × 6 уровней, drag&drop
- Две локации: «Лаборатория» (4 цепочки) и «Неон-Клуб» (кот-диджей и робо-танцор; открывается за 10000🪙 или 200💎, у каждой локации своё поле, открытая локация увеличивает офлайн-доход)
- Процедурные спрайты 128px с тенями, бликами, щёчками и аксессуарами уровней (ноль бинарных ассетов)
- Джинглы на WebAudio: у каждой цепочки свой тембр, арпеджио слияний растёт с уровнем, фанфары за достижения
- Яндекс.Метрика (`src/analytics.ts`): цели session_start, merge_high, order_done, ad_rewarded, ad_interstitial, purchase_*, zone_unlock, daily_claim, event_milestone
- Заказы, энергия с регеном, генераторы существ с кулдаунами
- Ежедневный бонус (7-дневная серия, спасение серии за рекламу), ежедневные квесты, Мемпедия
- Офлайн-доход с ×2 за rewarded, недельный лидерборд
- Сезонные события по датам из конфига (`src/events.ts`) с милстоунами наград
- Магазин: стартер-пак, пакеты кристаллов, «без рекламы»; синки: сундук (3% секрет), энергия, 7-й ряд
- Обёртка Yandex SDK: реклама с капами, облачные сейвы, платежи, Gameplay API — всё с dev-моками

## Структура

| Файл | Что там |
|---|---|
| `src/config.ts` | Баланс, цепочки, цены — весь «скин» игры |
| `src/events.ts` | Календарь сезонных событий |
| `src/state.ts` | Состояние, квесты, стрик, сериализация |
| `src/sdk.ts` | Обёртка Yandex Games SDK + моки |
| `src/shop.ts` | Витрина покупок и синки кристаллов |
| `src/sprites.ts` | Процедурная генерация спрайтов |
| `src/GameScene.ts` | Игровая сцена: поле, UI, панели |
