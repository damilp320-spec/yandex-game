# План разработки игры для Яндекс Игр

**Рабочее название:** «Brainrot Lab: Merge» (merge-idle казуалка в сеттинге итальянского брейнрота; запасной скин — «Уютная ферма», см. §13)
**Формат:** HTML5-игра для платформы Яндекс Игры, mobile-first
**Цель:** простая и лёгкая игра с высоким удержанием (retention) и деликатной рекламной монетизацией — реклама встроена в естественные паузы и в основном показывается по желанию игрока (rewarded), а не навязывается.

---

## 1. Почему именно такая игра

### Специфика платформы Яндекс Игры
- ~70% трафика — мобильные устройства, играют «на ходу» короткими сессиями по 3–10 минут.
- Аудитория широкая и казуальная: дети, взрослые, пенсионеры. Сложные игры отсеиваются на первых секундах.
- Топовые жанры платформы: merge, кликеры/idle, простые аркады, «2048»-подобные головоломки, симуляторы.
- Монетизация — почти полностью реклама (RTB через Yandex SDK): interstitial, rewarded video, sticky-баннер. Rewarded — самый доходный и самый «дружелюбный» формат.
- Игра живёт в iframe, загружается с CDN Яндекса → критичны маленький размер сборки и быстрый первый запуск.

### Почему merge + idle
- **Порог входа ~10 секунд:** вся механика — «перетащи два одинаковых предмета друг на друга». Понятно без слов любому возрасту.
- **Лучшие показатели удержания среди казуальных жанров:** merge даёт постоянные микро-достижения (каждое слияние — маленькая победа), idle-часть даёт причину возвращаться («пока меня не было, что-то накопилось»).
- **Идеальная почва для rewarded-рекламы:** множество естественных точек, где игрок *сам хочет* посмотреть ролик (удвоить офлайн-доход, получить энергию, открыть сундук) — реклама воспринимается как подарок, а не как наказание.
- **Дешёвый контент:** новые предметы, цепочки слияний и заказы добавляются без изменения кода — долгий жизненный цикл при малых затратах.

## 2. Концепция и основной цикл (core loop)

### Сеттинг
«Лаборатория брейнротов»: игрок выводит всё более абсурдных мем-существ в духе итальянского брейнрота (подробно — §13). Яркий, намеренно нелепый визуал и звук, целевая аудитория — дети/подростки (ядро трафика Яндекс Игр). Механически сеттинг — сменный скин: при затухании тренда перекрашивается в «Уютную ферму» без изменения кода.

### Основной цикл (30–60 секунд)
1. **Трачу энергию** → на поле появляются предметы (ростки, инструменты, ресурсы).
2. **Сливаю** два одинаковых → предмет уровнем выше (цепочки по 6–8 уровней: росток → куст → дерево → …).
3. **Выполняю заказы** персонажей (нужен предмет N-го уровня) → получаю монеты и опыт.
4. **Трачу монеты/опыт** → открываю новые зоны фермы, новые цепочки предметов, декор.
5. Энергия закончилась → пауза (или rewarded-реклама/ожидание) → возвращаюсь позже.

### Idle-слой (причина возвращаться)
- **Генераторы** (курятник, грядка, колодец) производят предметы, пока игрок офлайн.
- При возврате — экран «Пока вас не было…» с накопленным доходом и кнопкой **«Удвоить за рекламу»** (главная rewarded-точка).
- Копилка офлайн-дохода ограничена 4–8 часами → оптимальный ритм 2–4 захода в день.

### Сессия по дизайну
3–7 минут: энергия и таймеры генераторов естественно завершают сессию без фрустрации («я всё собрал, зайду позже»), а не обрывают её на взлёте.

## 3. Механики удержания («затягивание»)

| Механика | Как работает | На что влияет |
|---|---|---|
| Ежедневный бонус | 7-дневный цикл наград с растущей ценностью; 7-й день — «жирный» приз. Пропуск не сжигает прогресс полностью (мягкий streak) | D1–D7 retention |
| Ежедневные задания | 3 простых квеста в день («слей 20 предметов», «выполни 5 заказов») | Сессии/день |
| Офлайн-доход | «Пока вас не было…» + удвоение за рекламу | Возвраты, rewarded-показы |
| Коллекции/альбом | Редкие предметы из сундуков собираются в наборы → постоянная долгосрочная цель | D30 retention |
| Открытие зон фермы | Карта с «туманом»: каждая новая зона — новые цепочки и персонажи. Видимая недостижимая цель = мотивация | Долгосрочная цель |
| Заказы с таймером | 1 «горячий» заказ в день с повышенной наградой | Ощущение события |
| Лидерборд недели | Очки за слияния, сброс раз в неделю (через Yandex Leaderboards) | Соревновательность, соц. слой |
| Сезонные события | Раз в 2 недели: тематическая мини-цепочка (Новый год, урожай…) с уникальным декором | Возврат «отвалившихся» |
| Near-miss дизайн | Заказ почти собран, до новой зоны чуть-чуть — интерфейс всегда показывает «ещё немного и…» | Длина сессии |
| Ярлык и избранное | Предложение добавить ярлык на рабочий стол через Shortcut API SDK (в момент радости — после открытия зоны) | Возвраты вне платформы |

Принцип: **никакого наказания за отсутствие** (урожай не гниёт, прогресс не сгорает). Игрока тянет назад «пряник», а не страх потери — это критично для лёгкой, ненапряжной игры.

## 4. Монетизация: реклама без раздражения

### Философия
Реклама встроена в паузы, которые и так есть в игре, и в 80% случаев инициируется самим игроком ради выгоды. Игрок должен думать «о, халява», а не «опять реклама».

### Rewarded video — основной формат (по желанию игрока)
| Точка размещения | Награда | Ограничение |
|---|---|---|
| Экран возврата | ×2 к офлайн-доходу | 1 раз за возврат |
| Кончилась энергия | +20–30 энергии | 3–4 раза в день |
| Бесплатный сундук | Сундук с предметами/коллекционкой | Раз в 3–4 часа |
| Ускорение генератора | Мгновенное производство | 2–3 раза в день |
| «Горячий» заказ | ×1.5 к награде заказа | 1 раз в день |

Целевой показатель: **1.5–2.5 rewarded-просмотра на DAU** — это основной доход.

### Interstitial — строго дозированно
- Показ **только на естественных стыках**: возврат из зоны в общее меню фермы, завершение пачки заказов, конец сессии события.
- **Жёсткие правила:**
  - не чаще 1 раза в **3 минуты** (свой frequency cap поверх минимума SDK в 60 сек);
  - **никогда** в первые 3–5 минут самой первой сессии игрока (не убиваем FTUE);
  - **никогда** сразу после rewarded-ролика;
  - **никогда** посреди активного действия (перетаскивание, открытие сундука);
  - предварять коротким затемнением/заставкой «Реклама» — без внезапности.
- Ориентир: **не более 2–3 interstitial за сессию.**

### Sticky-баннер
- Только на «спокойных» экранах (карта, настройки), **не на игровом поле**. Включаем через A/B-тест: если ухудшает retention — выключаем.

### Технические требования к рекламе
- Перед показом любой рекламы — **пауза игры и звука**, после — корректное возобновление (требование модерации Яндекса).
- Обработка отказов SDK (нет заполнения/нет сети): игра не ломается, награду за rewarded выдаём только по коллбеку `onRewarded`.
- (Опционально, фаза 2) Внутриигровые покупки через Яндекс.Платежи: «отключить interstitial навсегда» + косметика. Это одновременно и доход, и жест уважения к игроку.

## 5. Интеграция Yandex Games SDK (чек-лист)

1. **Инициализация SDK** и `LoadingAPI.ready()` после реальной готовности игры (влияет на метрики платформы).
2. **Gameplay Start/Stop API** — вызовы при старте/паузе геймплея (обязательное требование модерации).
3. **Авторизация** — опциональная и ненавязчивая: играть можно анонимно; логин предлагаем ради облачных сохранений и лидерборда.
4. **Облачные сохранения** через Player Data API + локальный fallback (localStorage) для анонимов; троттлинг записи (не чаще раза в 5–10 сек, по ключевым событиям).
5. **Реклама**: `showFullscreenAdv` (interstitial) и `showRewardedVideo` со всеми коллбеками.
6. **Лидерборды** — еженедельный по очкам слияний.
7. **Локализация** через `environment.i18n.lang`: RU + EN + TR минимум (турецкая аудитория Яндекс Игр большая). Все тексты — во внешних словарях.
8. **Оценка игры**: `canReview`/`requestReview` — предлагать после «момента счастья» (открытие 2-й зоны), один раз.
9. **Shortcut API** — предложение ярлыка в удачный момент.
10. **Работа в iframe**: никаких внешних ссылок, попапов, запросов на сторонние домены; корректная работа тач- и мышиного ввода.

## 6. Технологический стек

- **Движок:** Phaser 3 (быстрый старт, огромное комьюнити, идеален для 2D-казуалок). Альтернатива — PixiJS (легче, но больше ручной работы) или Defold (меньше вес, выше порог входа). Рекомендация — **Phaser 3 + TypeScript + Vite**.
- **Размер сборки:** цель — первый экран ≤ 3–5 МБ (сжатые атласы WebP, ленивая подгрузка зон, музыка стримом/ogg). Быстрая загрузка = меньше отвалов до первого экрана.
- **Целевой FPS:** 60 на среднебюджетных Android; поле merge — простые спрайты, партиклы дозированно.
- **Сейвы:** единый JSON-стейт → сериализация в Player Data / localStorage; версионирование схемы сейва с миграциями.
- **Аналитика:** Яндекс.Метрика для игр + свои события (см. §9).
- **Баланс/экономика:** все параметры (цепочки, цены, энергия, награды) — в конфиг-таблицах (Google Sheets → JSON), чтобы балансировать без пересборки.

## 7. UX/UI и арт

- **Стиль:** мягкий flat/cartoon, крупные читаемые предметы, тёплая палитра. Никакого визуального шума на поле.
- **Управление:** один палец — drag&drop. Все кнопки ≥ 44px. Portrait-ориентация как основная, landscape — адаптив.
- **FTUE (первый опыт):** обучение ≤ 60 секунд, 4–5 шагов «рукой» (слей → выполни заказ → получи награду → открой генератор), без стен текста. Первая сессия должна закончиться на «вау» — открытии новой зоны.
- **Звук:** «сочные» звуки слияния (главный источник дофамина в merge), спокойный фоновый луп, кнопка mute на видном месте.
- **Доступность:** предметы различимы формой, а не только цветом; масштабируемый UI.

## 9. Аналитика и целевые KPI

**События:** шаги туториала, каждое слияние (агрегированно), выполнение заказа, показ/клик/отказ каждой рекламной точки, конец энергии, открытие зоны, возврат по офлайн-доходу.

| Метрика | Цель | Красная зона |
|---|---|---|
| Retention D1 | ≥ 35% | < 25% |
| Retention D7 | ≥ 12% | < 7% |
| Retention D30 | ≥ 5% | < 2% |
| Средняя сессия | 6–8 мин | < 3 мин |
| Сессий на игрока в день | ≥ 2.5 | < 1.5 |
| Rewarded на DAU | 1.5–2.5 | < 0.8 |
| Interstitial за сессию | ≤ 3 | > 4 (риск отвалов) |
| Конверсия FTUE (туториал до конца) | ≥ 80% | < 60% |

**Правило баланса рекламы:** если после включения/усиления interstitial D1 падает более чем на 3 п.п. — откатываем. Retention всегда приоритетнее краткосрочного eCPM: доход = удержание × показы, и первым множителем жертвовать нельзя.

**A/B-тесты после софт-ланча:** частота interstitial (180 сек vs 240 сек), sticky-баннер on/off, размер награды за rewarded-энергию, длина цепочек.

## 10. Пост-релизный план (LiveOps)

- **Каждые 2 недели:** сезонное событие (новая мини-цепочка + уникальный декор) — главный инструмент возврата ушедших игроков.
- **Ежемесячно:** новая зона фермы или новая производственная цепочка.
- **Постоянно:** правка баланса по аналитике, работа с отзывами на странице игры (модераторы Яндекса это учитывают в ранжировании).
- **Фаза 2 (при успехе):** покупка «без рекламы», косметика за Яндекс.Платежи, третья-четвёртая локализации, кросс-промо со «второй игрой» студии.

## 11. Риски и их снижение

| Риск | Снижение |
|---|---|
| Не пройдём модерацию (реклама без паузы, нет Start/Stop API и т.п.) | Чек-лист §5 закрыть до подачи; прогнать все сценарии показа рекламы |
| Слабый D1 (скучный кор) | Прототип-гейт на этапе 1: не идём дальше, пока 10-минутный плейтест не «залипает» |
| Interstitial душит retention | Консервативный старт (cap 240 сек), усиление только через A/B |
| Долгая загрузка → отвал до старта | Бюджет первого экрана ≤ 5 МБ, замер времени до `ready()` в аналитике |
| Экономика «ломается» (слишком быстро/медленно) | Вся экономика в конфигах; симуляция прогрессии в таблице до запуска |
| Клоны/конкуренция в жанре | Дифференциация сеттингом, коллекциями и событиями; скорость LiveOps |

## 12. Альтернативные концепции (запасные, тот же план применим)

1. **«Башня-стакер»** — аркада «ставь блок точно на блок»: цикл 30 сек, rewarded «продолжить после промаха», interstitial между забегами. Проще в производстве (4–5 недель), но ниже D7.
2. **Idle-кликер «Пекарня»** — чистый idle с престиж-механикой: сильный D30, rewarded-буcты ×2 дохода на время; кор-геймплей менее «тактильный», чем merge.

**Рекомендация — основной вариант (merge-idle):** лучший баланс простоты для игрока, глубины удержания и естественных, ненавязчивых рекламных точек.

## 13. Трендовая обёртка: итальянский брейнрот (по итогам ресерча)

### Что показал ресерч
- «Итальянский брейнрот» (Балерина Капучина, Бомбардиро Крокодило, Тралалеро Тралала, Тун Тун Тун Сахур и др.) — ИИ-генерированные абсурдные персонажи; тренд взлетел весной 2025, хэштег #brainrot набрал ~100 млрд просмотров в TikTok, его подхватили крупные бренды (KFC, Ryanair, ФК «Зенит»).
- Roblox-игра **Steal a Brainrot** (май 2025) поставила абсолютный рекорд игровой индустрии: **25,8 млн одновременных игроков** (октябрь 2025, больше рекорда Fortnite на 10+ млн) и **68+ млрд визитов к маю 2026**; игра продолжает обновляться в 2026, по ней снимают фильм. Вывод: **тренд жив и в 2026**, особенно у Gen Alpha.
- На Яндекс Играх «брейнрот» — стабильно горячий поисковый запрос детской аудитории; ниша merge-игр по теме не насыщена.

### Как встраиваем в игру
- **Merge-эволюция = формат самого мема.** «Эволюционные цепочки брейнротов» — популярный видеоформат; наша механика буквально его геймифицирует: сливай существ от простых к легендарным.
- **Цепочки-пародии:** кофейно-балетная, акулья, крокодильно-авиационная и т.п. Персонажи — **оригинальные, «в духе» тренда** (свои имена и дизайн, не копии): прямое использование чужих ассетов запрещено правилами платформы, а свои персонажи снимают юридический риск и риск модерации.
- **Заказы → «съёмки вирусных роликов»:** персонажи-«блогеры» просят существ для видео; награда — «просмотры» (опыт) и монеты.
- **Коллекции → «Мемпедия»** с редкостями common → epic → legendary → secret: переносим главный хук Steal a Brainrot (охота за редкостями) в казуальный формат. Секретные существа с шансом <1% из rewarded-сундуков.
- **Звук — половина вайба:** абсурдные короткие джинглы на слияниях высоких уровней, «озвучка» персонажей.
- **ASO на платформе:** «брейнрот», «merge», имена-пародии в названии/описании/тегах — бесплатный трендовый трафик из поиска.

### Риск затухания тренда и защита
- Вся тематика (имена, спрайты, звуки) лежит в конфигах = **скин**. Пивот на «ферму» или следующий тренд — 1–2 недели без изменения кода.
- Событийная система (§3) позволяет добавлять свежих мем-персонажей за считанные дни — скорость реакции на мемы сама по себе становится каналом привлечения.

## 14. Оценка потенциального дохода

**Формула:** доход/день = DAU × (R × eCPM_rew + I × eCPM_int) / 1000, где R и I — просмотры rewarded/interstitial на игрока в день.

**Вводные по рынку** (открытые отчёты разработчиков Яндекс Игр): средний eCPM по площадке ~20 ₽ и снижается с ростом конкуренции; rewarded дороже interstitial в 2–5 раз; сильная сезонность (декабрь ×1.5–2, январь–февраль — провал). Рабочие диапазоны: interstitial 15–40 ₽, rewarded 50–150 ₽.

### ARPDAU (доход с игрока в день)
| Сценарий | Показов на DAU | eCPM rew/int | ARPDAU |
|---|---|---|---|
| Пессимистичный | 1 rew + 3 int | 50/15 ₽ | ~0,10 ₽ |
| Базовый | 2 rew + 4 int | 90/25 ₽ | ~0,28 ₽ |
| Оптимистичный | 3 rew + 5 int | 140/40 ₽ | ~0,62 ₽ |

### Месячный доход (≈ ARPDAU × DAU × 30)
| DAU | Пессим. | Базовый | Оптим. |
|---|---|---|---|
| 500 (тихий старт без фичеринга) | 1,5 т.р. | 4 т.р. | 9 т.р. |
| 5 000 (удачный запуск) | 15 т.р. | 42 т.р. | 93 т.р. |
| 20 000 (фичеринг + тренд) | 60 т.р. | 168 т.р. | 372 т.р. |
| 100 000 (топ категории) | 300 т.р. | 840 т.р. | 1,86 млн ₽ |

**Честные ориентиры:** медианная новая игра без продвижения зарабатывает сотни рублей в месяц (порог выплаты — 3 000 ₽). Главные рычаги роста: попадание в подборки платформы (алгоритм Яндекса продвигает игры с высоким возвратом игроков), retention и трендовый поисковый трафик по «брейнрот»-запросам. Поэтому 80% усилий — в удержание, а не в плотность рекламы: произведение eCPM × показы упирается в потолок (и убивает retention), а DAU × дни жизни игрока — нет.

## 15. База знаний: удержание, внимание и реклама без «-вайба»

### Психология удержания
1. **Вариативное вознаграждение** (Скиннер): сундуки со случайной редкостью работают сильнее фиксированных наград; секретные персонажи с шансом <1% — главный двигатель Steal a Brainrot.
2. **Эффект Зейгарник:** незавершённое запоминается — всегда оставлять игрока с 1–2 «почти готовыми» целями на видном месте (заказ 4/5, зона 90%).
3. **Endowed progress:** шкала «10/12», а не «0/2» — начатое бросают реже, чем не начатое.
4. **Хук-модель** (Nir Eyal): триггер (накопился офлайн-доход) → простое действие (зайти и собрать) → вариативная награда (что в сундуке?) → вклад (прогресс, коллекция). Вклад повышает субъективную цену ухода из игры.
5. **Дофаминовый ритм:** микро-награда каждые 30–60 сек (слияние), средняя каждые 2–3 мин (заказ), крупная раз в сессию (зона/легендарка). «Сочность» фидбека — звук + партиклы + летящие числа — усиливает каждую.
6. **Peak-end rule:** сессия должна заканчиваться на позитиве — прощальный экран «завтра тебя ждёт …».
7. **Мягкий loss aversion:** streak можно «спасти» просмотром рекламы — точка, где удержание и монетизация усиливают друг друга без реальной потери для игрока.
8. **Достижимый социальный слой:** лига-лидерборд на 30 «таких же» игроков вместо глобального — шанс на топ есть у каждого.

### Внимание в первые 60 секунд (решают всё)
- Первое слияние — не позднее 10-й секунды после загрузки.
- Скриптованное «вау» (эффектное слияние высокого уровня) — в первые 2 минуты.
- Ноль текста: обучение жестами-подсказками («рука» показывает драг).
- Загрузка ≤ 5 сек на среднем смартфоне; время до `ready()` — метрика №1.

### Реклама без «-вайба»: 8 правил
1. **Обмен, а не прерывание:** 80%+ показов инициирует сам игрок ради выгоды.
2. **Награда видна до просмотра** («+30 энергии за ролик») и честно щедрая.
3. **Выдача мгновенная и с празднованием** — последняя эмоция от рекламы всегда положительная.
4. **Interstitial предсказуем:** только после экрана результата, с плашкой «Реклама через 3…2…1», никогда внезапно и никогда посреди действия.
5. **Отказ не наказывается:** закрыл rewarded — предложение просто остаётся доступным.
6. **Первая сессия — святое:** ни одного interstitial до первого «вау» и первого сохранения.
7. **Адаптивная частота:** лояльным (7+ дней streak) interstitial реже; новичкам в первые 3 дня — реже.
8. **Метрика-страж:** «доля сессий, оборванных в ≤10 сек после interstitial»; превысила порог — частота автоматически откатывается.
